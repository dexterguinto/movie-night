## Project Description

Movie Night is a web application that allows users to search for movies, view movie information, discover recommendations, and save movies to a personal watchlist.

## Deployed Website

https://movie-night-gm.vercel.app/

## How to Access and Use the Website

1. Open the deployed website using the link provided above.
2. Enter a movie title in the search bar.
3. Click the **Search** button to view available movies.
4. Select a movie to view its details.
5. Use the genre filters to browse movies by category.
6. Click **Surprise Me** to receive a random movie recommendation.
7. Add movies to the **Watchlist** to save them for later.
8. Movies saved to the watchlist can be viewed or removed at any time.

## API Used

**The Movie Database (TMDB) API**

The TMDB API is used to retrieve movie information such as:

* Movie titles
* Posters
* Release dates
* Ratings
* Genres
* Movie descriptions
* Runtime
* Cast and crew information

## Other Important Information

* The website requires an internet connection to retrieve movie information from the TMDB API.
* The watchlist uses browser LocalStorage to save the user's selected movies.
* The project was developed using HTML, CSS, and JavaScript.
* This product uses the TMDB API but is not endorsed or certified by TMDB.
